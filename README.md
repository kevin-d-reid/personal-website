# My Personal Website

This is where I promote who I am, what I can do, and share what I've learned through blog posts.

## Features

1. An about me page where you can learn more about me
2. A blog where I post all sorts of things I've learned about, or just want to share with you

## About The Website

Built with AstroJS and hosted on Vercel. 


## Technical Overview

Designed with security and performance in mind

1. A+ ranking on securityheaders.com
2. A+ ranking on Qualys SSL test
3. All sections green on hardenize.com
